# 2026-11-22 Windows 驱动仓库入口离线标定

更新日期：2026-11-22。状态：**实现与离线回放完成，未做 Windows 真机字段验收，未发布**。本文记录 Windows 本地 1920×1080 “驱动仓库”单页入口的样本事实、布局/阈值、回放结果和未覆盖项。行为契约以 [T5 §8](../specs/t5-zzz-inventory-traversal.md#8-windows-驱动仓库单页混排入口2026-11-22) 为准；平台输入补充见 [T2](../specs/t2-platform-capture-input.md)，补扫与合并见 [T6](../specs/t6-review-export-workflow.md#补扫不完整号位p-12-第一步)。

## 1. 范围与入口

- 游戏：简体中文《绝区零》本地 Windows 客户端，窗口模式，实际客户区 1920×1080，样本 DPI 120，游戏版本 3.3.0。
- 页面：游戏内“驱动仓库”，左侧 9×4 混排卡片，右侧固定详情；没有转盘位置切换。
- 入口：Windows 安装版默认改用 `PageDriveStorage`；显式 `YOUKAI_GAME_SOURCE=traverse` 仍进入旧的“驱动盘仓库”转盘入口。
- 不包含：自动登录/启动/从主菜单自动导航、云客户端、1920×1080 以外尺寸、其他语言、自动排序或计数对账。

## 2. 样本来源与保存边界

Jane 的 2026-11-22 私有 1080p 手工样本随附件包提供，包含原生像素裁剪和 `manifest.json`；原始整帧、附件包与 Windows 私有路径不进入仓库。样本包的 SHA-256 为 `35756ead6d3bacaadf0e70d8047584f83938af5dd0f45a6d84cb174d58ae80d2`。仓库只保存从样本导出的二进制字形掩码、布局常量和不含样板的回放测试；私有回放由环境变量 `YOUKAI_STORAGE_SAMPLES` 指向样本目录，未设置时跳过。

样本覆盖 31 个裁剪/状态：页面标题、漏斗开闭、面板打开/重置/仅选 S/仅选 S + 稀有度、六个号位的选中卡与详情、顶部/单行滚轮/底部/底部复检列表。样本没有全空列表、相邻详情完全相同、完整库存计数对账、3 副词条详情、未锁定/已弃置卡或非粉色头像的已装备样本。

## 4. 号位与接纳

- 每张卡左上角有号位图标；详情标题后缀有 `[N]`，标题下方有独立号位图标。
- 当前样本的 1–4、6 号位为数字形状，5 号位为 S 形状；S 形状按号位 5 处理，不是稀有度字母。稀有度由金色 S 徽章和范围/品质证据单独确认。
- 卡片徽标在 34×26 的声明窗口内搜索 26×18 掩码，按前景 F1 分类；每个号位保留多个真实列/滚动状态掩码。卡片接受下限 0.88、领先次优号位 0.04；详情独立徽标接受下限 0.90、领先 0.06。低于下限报未知，差距不足报冲突，不取第一个模板。
- 选中卡滚出视口后，详情可能仍是旧卡；只凭同号位或新帧不接纳，必须有本次动作后的选中/详情变化、位置对应或完整稳定比较证据。遍历层卡片与详情独立徽标不一致时停止；标题 `[N]` 与遍历号位不一致时由识别侧待校对，二者不互相覆盖。
- 识别侧把名称行 OCR 的 `[N]` 与遍历确认的卡片号位交叉核对；冲突时记录 `slotPositionMismatch` 并把槽位置为未知。

## 5. 滚动与账目

驱动仓库没有选中框锚点时，不使用“归一化特征最佳行数”作为唯一判据。实现要求两个独立证人同时指向唯一行数：

1. 滑块按自身几何移动的行程符合声称行数（方向 + 幅度，±20%，且不与其他候选行程重叠）；
2. 前后视口重叠区域的占用与卡片徽标逐格一一对应，全部重叠占用卡的号位已知且相同。

顶部/底部由滑块端点加稳定不移动的列表确认；底部样本额外一格滚轮后最后一行和滑块不变。任何证人缺失、多个行数拟合、号位未知/冲突或占用不一致都保留最后已证明账目并停止/降级，不猜跳过行数。

只有完整连续的一遍混排遍历、范围证明、顶部/末端证明和真实空格记录齐备时，才把格位映射到六份号位账目。范围限定补扫仍遍历整个混排视口，只接纳声明号位，其他卡记 `outOfScope`；整体覆盖固定为 `partial`，不能静默回退为整仓扫描。JSON/CSV v2 与旧记录行为不变。

## 6. 回放结果

私有回放 `TestStoragePrivateHandoff` 通过：

- 初始/顶部、单行滚轮后、底部、底部复检四类列表帧均判为驱动仓库；顶部和单行后的 36 个混排卡片号位全部可读且正确。
- 单行滚轮由滑块行程 + 卡片徽标重叠验证为 1 行；选中卡离开视口后不再有选中锚点。把卡片徽标窗口遮黑的同一对照帧返回 Undecided，没有回退到重复卡面的整屏特征。
- 底部最后一行 1 个占用卡 + 8 个空位；最后卡号位为 6，底部复检为 Stationary。
- 六份详情裁剪的独立号位（1–6，含 5 的 S 形图标）全部正确；面板打开、重置、仅选 S、稀有度排序四种状态通过。
- 页面标题、漏斗、选中框、占用条、管理锁和滚动条端点均按本布局匹配。

公开单测覆盖布局/档位校验、字形未知/冲突、混排格位账目、范围限定报告、完整/失败/范围未证明的号位结论、卡片/详情号位门禁，以及 OCR 标题号位与遍历号位的冲突处理。命令见[开发指南](../development.md#真实遍历windows-本地客户端1920x1080-首次全量真机扫描完成参数未标定)。

## 6.1 R1 修订与回归

Sol 的 R1 审查提出了八项必修项；本轮在独立 worktree 修复并补充可维持的回归证据：

- **顶部门禁：** `topConfirmed` 接受已证明的驱动仓库顶部，不再只认旧 `PageWarehouse`；定向测试覆盖静止顶部。
- **滚轮几何：** Windows 串行 actor 对滚轮执行与拖拽首批相同的实时重测/前台/几何/落点检查；验证预检期间移动 1 px 会返回 `staleGeometry` 且零事件。
- **旧详情基线：** 点击前的当前稳定帧成为详情比较基线，不再优先使用上次接纳帧；定向序列验证点击前后同号位旧详情不会作为变化接纳。
- **补扫参考格：** 同详情参考往返只选声明号位内的卡；范围外参考卡不被点击，测试覆盖 3 号位补扫不得选 4 号位。
- **范围变化：** 已证明 S 后列表变 `FilterClear` 会停止；打开面板后任一后续面板帧必须继续命中“稀有度”模板，失配/变化不再被空标签忽略。
- **滚动证据：** 滑块起点和终点必须同向移动（仅轨道端点夹边例外）；重叠匹配还要求目的格至少有一个占用/号位变化，静止的同号位网格不能靠重复槽位证明一行。驱动仓库固定使用证据匹配器，`legacy` 不再能绕过移动滑块的末端检查。
- **空格与保存：** `applyTransition` 对已证明的空格不再要求号位徽标；保存的储存页账目保留 `empty` 空格和 `outOfScope` 卡，补扫报告仍能看到范围外跳过依据。
- **旧入口：** 共享准备/失败文案同时指向“驱动仓库（旧入口为驱动盘仓库）”；旧入口的转盘位置不再进入驱动仓库 OCR 号位交叉校验，也不会显示“卡片槽位”诊断。

新增的正常入口脚本化动作序列通过真实 `Inventory` 与扫描内核执行：从中段回顶、两段连续推进、独立末页复检、54 件逐件号位归属与 `complete` 覆盖；另一条只补扫 3 号位，断言 9 次接纳、零范围外点击、覆盖 `partial`，并保存 45 个 `outOfScope`。脚本化匹配器提供页面/详情/滚动证据，像素证据仍由私有回放和独立匹配器测试覆盖。没有把临时复现用例新增为持久测试设施。

## 6.2 R2 修订与证据

Sol 的 R2 审查指出同一区域的五项回归；本轮按统一规则重做，而不是按复现数字加特例：

- **方向一致：** 严格滑块行程保留物理符号，再与声明行方向比较；不再先取绝对值。卡片映射前进一行而滑块上移的合成帧保持未接纳，正向对照仍证明一行。
- **边界静止：** 顶部复检要求点击前帧已在顶部且滑块两边都在抖动下限内；末端静止要求滑块任一边都没有超过下限的移动。单边 6 px 移动不再被共享 Stationary/MAD 路径当作静止。
- **重开面板：** 准备完成后重开的面板仍须命中“稀有度”模板且 S 为 `Active`；S 变 `Clear`、未知或不可读都立即停止，详情等待中的面板帧同样经过这条门禁。
- **空格身份：** 账目追加时为每个观察格（包括空格）写入实际绝对行、列和首次观测帧；保存的 `empty` 不再统一落到 `(0,0)/frame 0`。
- **入口与补扫证据：** 脚本从中间视口开始，精确断言两次顶部滚轮、53 次卡片点击、两次推进滚轮和独立末页复检，并核对落点、逐件唯一身份与右栏详情归属；同号位同详情且唯一参考在范围外时，补扫在参考归属前停止且不点击范围外卡。

公开测试覆盖上述五条；临时复现用例仍只读复用，不进入提交。

## 6.3 R3 修订与证据

Sol 的 R3 审查只保留三项，本轮按同一证据规则收敛：

- **选中框路径：** 驱动仓库有选中锚点时也进入与无选中框相同的滑块方向+卡片徽标重叠证据；反向滑块不再被选中+特征分支接受。私有单行裁剪只改三处选中探针后仍接受一行；原始真实裁剪对照不变。
- **顶部独立静止：** 顶部确认要求列表像素独立证明零位移，同时具备点击前顶部、两端滑块静止和顶部标记；共享 Stationary 的 Undecided/MAD 结果不再单独放行。
- **状态机证据：** 正常入口和补扫测试按接纳帧 ID 读取实际帧的选中卡、右栏详情和保存图像，并核对精确滚轮刻度、滚轮落点及卡片点击中心。临时把转场接纳改成点击前图像+帧 ID 时，全扫和补扫均失败；变异已还原且不提交。

临时复现只读复用；没有新增真机或发布声明。

## 6.4 R4 相邻视口修订

Sol 的 R4 审查只剩相邻视口的选中状态两项：

- **同列重复号位：** 可靠选中、两端滑块同向和占用徽标重叠全部对应时，同列号位在两个视口重复不再阻止一行；选中状态提供实例证据，仍保留卡面可区分性和 27 个重叠对应。
- **跨列冲突：** 两个选中框都可读但跨列时不再降格进入无锚点分支；匹配器返回未决，不提交受矛盾影响的格位。

正常调用链现在按选中一致/缺失/冲突分类：缺失才使用无锚点的“目的格必须变化”规则；冲突直接停止。合成正反例和原始私有顶部/底部样本通过；R4 的相邻选中正例/跨列反例是合成帧，原始样本只覆盖顶部/底部静止，不是现场滚动验收。

## 7. 未覆盖项与结论边界

以下项目没有本批样本，不能写成已支持：

- 全空列表、单件/不足一行、相邻且详情完全相同的驱动盘。
- 完整库存与页面计数的逐件对账；页面可见的“1009/3000”一类计数不与本次 S 范围对账，不能据此宣布覆盖完整。
- 3 副词条详情、未锁定/已弃置卡、粉色头像之外的其他代理人/装备状态。
- 1920×1080 以外的尺寸、Windows/macOS 云客户端、其他语言。
- 真实像素回放中的回顶滚轮完整动作序列、选中卡在视口内时的滚轮序列、整次遍历的详情稳定/重访路径；本批的像素回放只覆盖静止裁剪和一次单行滚轮前后帧，状态机级正常入口由脚本化动作序列覆盖，顶部/末端确认沿用共享契约。
- Windows 真机字段验收、三轮整仓对账、安装包升级链；当前只有离线回放和公开单测。R3 的选中路径对照来自真实私有裁剪加三处选中探针改造，顶部反向对照是合成帧；二者都不是 Windows 平台验收。

因此本次交付是**候选实现**：安装版默认接线与旧入口保留已完成，但不能据此宣称驱动仓库已在真机支持或完成字段验收。后续真机轮次应优先补全空仓、相邻同详情、底部 1+8 与完整库存对账，并保留每件的卡/详情号位证据。
