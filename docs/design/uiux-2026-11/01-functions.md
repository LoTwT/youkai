# 01 功能清单

第一阶段草案（2026-11-03）。本文从规格出发，列出用户要完成的每件事。每项只写用户视角的前提、结果和失败情况，规则正文以“出处”列的规格为准。代码引用基于 `main` 的 `f23c836`。

编号 `F-xx` 供 03–05 引用。“平台”列：通用 = 两类用户相同；Win / mac = 只适用或主要差异在该平台。

A–G 节按现有规格写。2026-11-03 检查点 1 后：首版只支持 Windows 本地客户端，表中 mac 的内容仅作后续版本参考；已决定的提案对各功能的影响和新增功能见 [H 节](#h-2026-11-03-决定的影响与新增功能)。
