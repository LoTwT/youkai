标注

  1. 首次与回访使用同一份准备检查（P-03），检查项默认全部展开；不满足项排在最前，标题行的标签写“n 项需要处理”。检查结果带检查时间，窗口重新获得焦点或超过 10 秒时自动重查（09 §4.8）。
  2. 失败项展开“为什么 + 怎么做”。权限是首次使用主路径上的正常步骤（W1 步骤 3–4），引导文案“先从托盘退出 youkai，再以管理员身份运行”（P-05）。
  3. 需要游戏在前台的检查不给结论，只标“点开始后检查”，并提示先打开驱动盘仓库页（C-07）。
  4. 须知在底部操作条左侧（方案 C）；预计耗时没有历史时写“未知”（P-14）。
  5. 按钮在操作条右侧；禁用时原因写在按钮左侧（09 §4.1）。失败项展开后清单变长，操作条仍固定可见。初始焦点在“退出 youkai”。
焦点顺序：导航轨 → 重新检查 → 退出 youkai → 更换目标 → 开始扫描（禁用）。
相关规格：08 §1、§1.1、§1.3。
