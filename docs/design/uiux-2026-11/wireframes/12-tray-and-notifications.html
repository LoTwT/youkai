youkai · 第二段（收尾结束；先撤下第一段再发）

3

关闭窗口后，youkai 的图标在任务栏右侧的通知区域；Windows 11 可能把它收在 ^ 里面。点图标可以重新打开，右键图标可以退出。

任务栏按钮：第二段通知发出时同时闪烁（FlashFrame），直到窗口获得焦点；窗口已隐藏到托盘时没有任务栏按钮，此项不生效。

标注

  1. 托盘菜单第一行是禁用的状态行；扫描中“打开”写作“停止扫描并打开”（T1 §2、D-03）。MyGo 菜单项可运行时改文字与启用状态（MenuItem.SetLabel / SetEnabled）。左键单击行为 P-02 实测前不改（#115）。
  2. MyGo v0.6.2 在 Windows 上的通知就是托盘气泡（Windows 10+ 显示为通知横幅），标题 ≤ 63 字、正文 ≤ 255 字。同一 ID 替换只是 API 约定，Windows 后端没有实现，所以发第二段前先 Close() 第一段再 Show()，否则会多出一个临时托盘图标（09 §4.7）。点击只打开 youkai 并进入记录摘要，不启动扫描。准备超时不发第一段。通知中心能否找回错过的通知待实测（09 §4.9 T-01）。
  3. 首次隐藏提示在隐藏前以对话框出现一次（P-10；08 §9 按推荐写入，待 11 Q-03 确认）；之后可在设置重看。单按钮对话框不受“主按钮在左”的限制（09 §4.1）。托盘不可用时不出现，关窗直接退出（08 §7）。
按“扫描中完全没有反馈”的假设，托盘悬停提示与菜单状态行都不作为扫描中的反馈渠道（06 §3 第 1 条）。
相关规格：08 §7、§8、§9；09 §4.7、§4.8；10 R-09、R-18。
